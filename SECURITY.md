# Security Policy

## Reporting a vulnerability

Please report suspected security issues privately through GitHub's security advisory feature. Do not open a public issue containing credentials, personal speech data, exploit details, or other sensitive information.

Include the affected component, reproduction steps, potential impact, and any suggested mitigation. Reports will be acknowledged as soon as possible and handled according to severity.

## Data safety

This project may process voice recordings and transcripts. Never commit real user recordings, access tokens, `.env` files, local databases, cloud credentials, or personally identifiable information. Use synthetic or explicitly licensed samples in tests and documentation.
